Game 0.7.2 improves online reconnects, Temporal Uplink graphics and everyday controls.

## What changed

### Join another online match without restarting
**Before:** Leaving a lobby or failing to join could leave the connection in an
unfinished state. A later attempt could report that the host did not answer.
**Now:** The game clears the old connection so you can host or join another lobby
without restarting the game.

### See the Temporal Uplink map without the lighting washout
**Before:** The Uplink's holographic map and screen-copy effects could be missing.
Holding it in What Lies Below could also produce a pale rectangle and severe
lighting washout.
**Now:** The shared renderer restores the map and screen-copy effects and corrects
the visibility checks behind the reproduced Uplink washout. This does not claim
to fix every reported black box or lighting issue elsewhere in the game.

### Richer default colors
**Before:** The shared renderer's final picture lacked the intended contrast and
color treatment.
**Now:** A consistent console-style contrast, brightness and saturation treatment
is applied automatically. No settings adjustment is needed. The legacy Mac
OpenGL renderer retains its previous colors; exact original-console parity has
not been established.

### Team markers fit names and different screen shapes
**Before:** The halves of a team skull could separate or distort, and the marker
and name could fall out of alignment on different display shapes.
**Now:** Skull halves stay joined without a name and open around a visible name,
with consistent proportions and positioning.

### More reliable mission-computer confirmation
**Before:** Holding another button or using a high native frame rate could cause
a mission-computer confirmation press to be missed.
**Now:** Confirmation handling preserves the press through those input and timing
conditions. The exact reported CachyOS controller scenario still needs live
confirmation; this is not a claim that every controller issue is fixed.

### Native Linux ARM64 source builds
**Before:** ARM64 Linux devices had no maintained native game build target.
**Now:** Developers can build the shared game runtime for ARM64 Linux. This release
does not provide an ARM64 game ZIP. Physical ARM64 gameplay, drivers and
performance still need verification.

## Known issues and compatibility

Packages target Windows x64, Apple Silicon Mac and experimental Linux x64:

- Windows: Windows 10/11 x64, .NET Framework 4.8 and a suitable Vulkan or OpenGL driver.
- Mac: Apple Silicon and macOS 27 or newer for this game package. The application
  is ad-hoc signed and is not notarized. Intel Macs are unsupported.
- Linux: x64, Ubuntu 24.04 / glibc 2.39 or newer, a desktop display and suitable
  graphics drivers. Wayland requires XWayland for the launcher. Physical Linux
  GPU, Steam Deck and Linux ARM64 gameplay acceptance remain incomplete.

Everyone in multiplayer should use matching 0.7.2 builds and game data. Do not
mix 0.7.1 and 0.7.2 in a match. Community Online uses a relay without player port
forwarding; Private Server owners need working UPnP or forwarding. Online Arcade
and bots remain experimental. Story co-op needs its separate compatible testing
build. [Multiplayer instructions](https://github.com/TheDoffman/timesplitters-future-perfect-pc/blob/main/docs/players/multiplayer.md).

Original 60 FPS remains the default and recovery choice; higher frame rates
remain beta. Full-campaign completion and complete graphics/audio fidelity are
not established by these bounded release checks. Native Mac startup movies remain
skipped, and the existing Apple Silicon physics-rounding discrepancy remains.
This update does not claim to fix Siberia vehicle lag or improve FPS through the
new frame-pacing diagnostics.

Updates retain imported game data, saves, settings and installed/custom textures.
Enhanced textures remain an optional download; these game ZIPs omit the pack.
Keep Data, Settings, Saves and Textures when replacing a portable installation.
Back up personal saves before testing. Original game files are required and are
not included in these downloads.
